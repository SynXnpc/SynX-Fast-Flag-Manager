# SynX

External Roblox Fast Flag manager.

Import a JSON, select your process, hit **Apply**.

---

### Requirements

| | |
|---|---|
| OS | Windows 10 / 11 |
| Runtime | [.NET 8 Desktop](https://dotnet.microsoft.com/download/dotnet/8.0) |
| Other | Roblox running · Run as administrator |

---

### Usage

1. Join a Roblox game  
2. Open SynX as admin  
3. **Import** your flag JSON  
4. **Apply**
